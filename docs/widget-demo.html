🚀 Quick Start

Install and use the widget in just 3 steps:

1. Copy Component Files

# Copy React component to your project cp src/components/SupplementComparisonWidget.tsx /your-project/src/components/ cp src/components/SupplementComparisonWidget.css /your-project/src/components/

2. Serve JSON Data

# Copy data files to your public API directory cp -r output/step9-embeddable-module /your-website/public/api/products/

3. Use in Your App

import SupplementComparisonWidget from './components/SupplementComparisonWidget'; function App() { return ( <SupplementComparisonWidget supplement="vitamin-d" defaultLimit={20} /> ); }

🎯 Use Cases

Blog Post Embed

Embed the widget in your supplement review articles:

<article> <h1>Best Vitamin D Supplements 2025</h1> <p>After extensive research...</p> {/* Embedded comparison widget */} <SupplementComparisonWidget supplement="vitamin-d" compact={true} defaultLimit={10} /> </article>

Comparison Page

Create dedicated supplement comparison pages:

<SupplementComparisonWidget supplement="magnesium" showSearch={true} showFilters={true} />

User Selection

Let users choose their supplement:

{/* Widget shows supplement selector first */} <SupplementComparisonWidget />

🔧 Customization Options

Available Props

  • supplement: Pre-select a supplement category
  • apiEndpoint: Custom API base URL
  • defaultLimit: Number of products to show (10, 20, 50, 100)
  • showSearch: Enable/disable search bar
  • showFilters: Enable/disable filter buttons
  • compact: Use compact layout (smaller width)

Custom Styling

Override CSS variables to match your brand:

.supp-widget { --primary-color: #your-brand-color; --border-radius: 12px; --spacing-unit: 24px; } .supp-filter-btn.active, .supp-buy-btn { background: #your-brand-color; }
